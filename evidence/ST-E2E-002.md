## Criteri

1. Solo 1280 px: `VISTE` in `apps/web/e2e/supporto.ts` ha una sola vista; nessun e2e di ST-UX-003A toccato.
2. Build per impronta: `apps/web/e2e/prepara.ts`, impronta in `apps/web/.next/.e2e-hash`; giri 2 e 3 senza build. `TRAVELOPS_E2E_SENZA_BUILD=1` invariato.
3. Modalità mirata: `npm run e2e:mirati` (`apps/web/scripts/e2e-mirati.ts`), tabella in `apps/web/e2e/e2e.config.json`; file non mappato -> suite completa. `npm run e2e` resta la suite completa.
4. Nessuna `waitForTimeout` né `setTimeout` in `ux003b-bozza-conferma` e `ux003b-bozza-menu`: attese su fine animazioni e ritorno del focus.
5. Questa pagina; suite verde due volte di fila (giri 2 e 3).
6. `docs/prove-e2e.md`.
